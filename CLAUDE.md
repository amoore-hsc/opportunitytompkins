# Notes for Claude

## Pull requests
Whenever you open a pull request in this repository:
- **Title:** name it after the feature or fix it delivers, in plain English
  (e.g. "Keep job scraping within Firecrawl's free plan"), never the branch name.
- **Description:** explain what the change does and why, written for a
  non-developer owner: what visitors or admins will notice, what changed behind
  the scenes, any Supabase/Netlify steps needed before or after merging, and how
  it was tested.
